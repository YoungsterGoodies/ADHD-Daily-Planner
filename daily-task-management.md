# Daily Task Management Template

A simple template for managing today's tasks — dump everything out of your head, pick the top 3, and give each task a first step and a time block.

## 1. Brain dump

Write down every task on your mind. Do not sort or judge them yet — just get them out of your head.

## 2. Top 3 priorities

Pick the three tasks that would make today feel complete if nothing else got done. Write the first step of each one, not the whole task.

1. Task: _______________ — First step: _______________
2. Task: _______________ — First step: _______________
3. Task: _______________ — First step: _______________

Work in 25-minute blocks with 5-minute breaks. Tick a task Done as soon as you finish it.

## 4. Done today

Write each finished task here as you complete it. Seeing the list grow is the proof the day worked.

## 5. Evening reset (5 minutes)

- Tick what got done.
- Move anything unfinished to tomorrow's list.
- Pick tomorrow's top 3.
- Clear the brain dump so tomorrow starts fresh.

## How it fits with the other files

- Use `daily-checklist.md` for the morning routine and the evening reset.
- Use `weekly-checklist.md` on Sunday to set the week's top 3 and spread tasks across days.
- Use `habit-tracker.md` to tick your three daily habits.
- Use `planning-guide.md` to learn the whole system in 5 steps.
- Use `notion-dashboard-guide.md` to build the same system as a one-page Today dashboard in Notion.

## Benefits

- Fewer things held in mind — the brain dump empties your head onto the page.
- Clear priorities — three top tasks keep the focus on what matters today.
- Easier starts — a written first step removes the decision of where to begin.
- Less overwhelm — tasks are split into small steps with a time block each.
- A calm close — the evening reset shows what got done and what moves to tomorrow.
