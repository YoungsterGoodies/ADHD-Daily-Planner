# Simple Habit Tracker

Copy this file for the week. Pick three small habits, tick them each day, count the week at the end.

## How to use

1. Write down 3 habits — keep them small enough to do every day.
2. Do each habit at the same time every day, if you can.
3. Tick the box for that day when you do it.
4. A missed day is fine — start fresh the next morning.
5. Count your total at the end of the week.
