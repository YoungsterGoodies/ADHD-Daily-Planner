# Morning Routine Checklist

A short morning routine — about 15 minutes, same order every day, so the day starts without decisions.

## The routine

- [ ] Wake up and get out of bed — no scrolling first
- [ ] Drink a glass of water
- [ ] Open a window or step into light for a minute
- [ ] Make the bed (one minute, done is enough)
- [ ] Wash up and get dressed
- [ ] Eat something simple for breakfast
- [ ] Open `daily-checklist.md` and write today's top 3 priorities
- [ ] Pick the first task and write its first step
- [ ] Start the first task — even 5 minutes counts

## If a step is missed

Skip it and move to the next one. A missed step is not a failed morning — the routine bends, it does not break. Do not restart from the top.

## Keep it small

- The whole routine fits in about 15 minutes.
- Keep the same order every day so it becomes automatic.
- If mornings are rushed, do only the first three steps and the top 3 — that is enough.
- Prepare the night before: clothes out, top 3 written in the evening reset.

## How it fits with the other files

- Use `daily-checklist.md` right after this routine for the full day: morning routine, top 3 priorities, work blocks, evening reset.
- Use `daily-task-management.md` to list all tasks and give each one a first step and a time block.
- Use `habit-tracker.md` to tick your three daily habits.
- Use `weekly-checklist.md` on Sunday to set the week's top 3.
- Use `planning-guide.md` to learn the whole system in 5 steps.
- Use `notion-dashboard-guide.md` to build the same system as a one-page Today dashboard in Notion.

## Benefits

- Fewer decisions in the morning — the same steps in the same order, every day.
- A calm start — water, light and a made bed before any screen.
- Clear priorities — the top 3 are written before the day pulls you in many directions.
- Easier starts — the first task already has a first step written down.
- A forgiving routine — a missed step is skipped, not punished, so the morning still works.
