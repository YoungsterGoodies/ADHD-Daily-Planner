# ADHD Daily Planner

A simple and flexible daily planning resource designed to help people organize everyday tasks.

Free to use and adapt for personal planning. Part of the YoungsterGoodies free resource library — our complete planners are on Etsy.

## Features

- Daily task checklist
- Top priorities section
- Morning routine tracker
- Evening review checklist
- Weekly planning checklist
- Simple habit tracker
- Daily task management template
- Simple planning guide
- Notion dashboard guide
- Flexible daily planning
- Simple Markdown format

## What's inside

- `daily-checklist.md` — the daily checklist: morning routine, top 3 priorities, short work blocks, evening reset
- `weekly-checklist.md` — the weekly planner: week focus, top 3 weekly priorities, one small step each day, weekly review
- `habit-tracker.md` — the habit tracker: 3 habits, daily ticks, weekly count and streak
- `daily-task-management.md` — the daily task management template: brain dump, top 3 priorities, task list with first step and time block, done list, evening reset
- `planning-guide.md` — the planning guide: how to use the daily, weekly and habit files together
- `notion-dashboard-guide.md` — the Notion dashboard guide: build a one-page Today dashboard in Notion, with Benefits and FAQs
- `README.md` — this file: how to use the checklists

## How to use

Start with `planning-guide.md` — it explains the whole system in 5 steps.

- **Every day:** open `daily-checklist.md`. Copy it for today, or print it. Write down your top three priorities, tick tasks off as you finish them, and do a 5-minute evening reset: write tomorrow's top three and tick today's habits.
- **Every week:** open `weekly-checklist.md` on Sunday. Set the week's focus and top 3 priorities, give each day one small step, and review the week at the end.
- **Every day:** open `habit-tracker.md`. Pick three small habits and tick the box each day you do them.
- **Every day:** open `daily-task-management.md` to list all tasks, pick the top 3, and give each one a first step and a time block.
- **In Notion:** open `notion-dashboard-guide.md` to build a one-page Today dashboard with the same system.

- Fewer decisions in the morning — the day starts from a short list, not a blank page.
- Clear priorities — three top tasks keep the focus on what matters today.
- Easier starts — one small first task makes it simpler to begin.

## Frequently Asked Questions

1. Is this daily planner free to use?
Yes. This checklist is free to download, copy and use for your own daily planning.

2. Do I need Notion to use it?
No. This is a simple Markdown file. You can use it in any text editor, notes app or on paper.

3. Is this planner dated?
No, it is undated. You can start it on any day and reuse it every day.

4. Can I print this checklist?
Yes. Copy it into a document or print the page and tick the boxes by hand.

5. How do I choose my top three priorities?
Pick the three tasks that would make today feel complete if nothing else got done.

6. What if I do not finish everything today?
Move unfinished tasks to tomorrow's list. The evening review is for that, not for judging the day.

7. Is this made for people with ADHD?
It is designed with ADHD-friendly planning in mind — short lists, clear priorities and flexible structure.

8. Can I use the same checklist every day?
Yes. Copy the template each morning and fill it in fresh.

9. Does it work for students and remote workers?
Yes. The checklist fits study tasks, work tasks and home tasks the same way.
