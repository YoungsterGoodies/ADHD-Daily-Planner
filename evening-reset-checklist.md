# Evening Reset Checklist

A short evening reset — about 10 minutes, same order every day, so the day ends clean and tomorrow starts without decisions. Pair it with the morning routine: the reset writes tomorrow's top 3, the morning routine starts them.

## The routine

- [ ] Close the day — put work away and stop starting new tasks
- [ ] Tick today's habits in `habit-tracker.md`
- [ ] Tick off today's top 3 in `daily-checklist.md` — done is done, undone moves on
- [ ] Move anything unfinished to tomorrow — one line, no re-planning the whole day
- [ ] Write tomorrow's top 3 priorities
- [ ] Pick tomorrow's first task and write its first step
- [ ] Lay out tomorrow: clothes, bag, keys, wallet, phone charger
- [ ] Quick tidy — clear the desk or table for five minutes, nothing more
- [ ] Write one win of the day — the thing that went well today

## If a step is missed

Skip it and move to the next one. A missed step is not a failed evening — the reset bends, it does not break. Do not restart from the top, and do not carry the day's unfinished work into the night.

## Keep it small

- The whole reset fits in about 10 minutes.
- Keep the same order every day so it becomes automatic.
- If evenings are rushed, do only the first three steps and tomorrow's top 3 — that is enough.
- The reset is the night-before half of the morning routine: tomorrow's top 3 are written here, not in the morning.

## How it fits with the other files

- Use `daily-checklist.md` right after this reset for the full day: morning routine, top 3 priorities, work blocks, evening reset.
- Use `morning-routine-checklist.md` the next morning — it starts from the top 3 this reset wrote.
- Use `daily-task-management.md` to list all tasks and give each one a first step and a time block.
- Use `habit-tracker.md` to tick your three daily habits.
- Use `weekly-checklist.md` on Sunday to set the week's top 3.
- Use `planning-guide.md` to learn the whole system in 5 steps.
- Use `notion-dashboard-guide.md` to build the same system as a one-page Today dashboard in Notion.

## Benefits

- Fewer decisions in the morning — tomorrow's top 3 and first step are already written.
- A clean ending — unfinished work is moved, not left circling in your head.
- A forgiving routine — a missed step is skipped, not punished, so the evening still works.
- A visible win — one line a day about what went well, even on a hard day.
- A calmer tomorrow — clothes, bag and desk ready before the morning rush.
