# ADHD Daily Planner

A simple and flexible daily planning resource designed to help people organize everyday tasks.

## Features

- Daily task checklist
- Top priorities section
- Morning routine tracker
- Evening review checklist
- Flexible daily planning
- Simple Markdown format

## Who Is This For?

This resource may be useful for:

- People interested in ADHD-friendly planning
- Students managing daily tasks
- Remote workers organizing projects
- Anyone looking for a simple daily checklist

## How to Use

1. Open the daily planner file.
2. Download or copy the Markdown template.
3. Add your daily tasks.
4. Choose a few priorities.
5. Review and adjust your plan throughout the day.

## Example Daily Checklist

- [ ] Review today's tasks
- [ ] Choose three priorities
- [ ] Start one small task
- [ ] Take regular breaks
- [ ] Review completed tasks

## Benefits

- Fewer decisions in the morning — the day starts from a short list, not a blank page.
- Clear priorities — three top tasks keep the focus on what matters today.
- Easier starts — one small first task makes it simpler to begin.
- Less overwhelm — tasks are written down instead of held in mind.
- Flexible structure — the plan can change during the day without starting over.
- A calm close — the evening review shows what got done and what moves to tomorrow.
- Simple to reuse — the same checklist works every day, dated or undated.

## Frequently Asked Questions

1. Is this daily planner free to use?
Yes. This checklist is free to download, copy and use for your own daily planning.

2. Do I need Notion to use it?
No. This is a simple Markdown file. You can use it in any text editor, notes app or on paper.

3. Is this planner dated?
No, it is undated. You can start it on any day and reuse it every day.

4. Can I print this checklist?
Yes. Copy it into a document or print the page and tick the boxes by hand.

5. How do I choose my top three priorities?
Pick the three tasks that would make today feel complete if nothing else got done.

6. What if I do not finish everything today?
Move unfinished tasks to tomorrow's list. The evening review is for that, not for judging the day.

7. Is this made for people with ADHD?
It is designed with ADHD-friendly planning in mind — short lists, clear priorities and flexible structure.

8. Can I use the same checklist every day?
Yes. Copy the template each morning and fill it in fresh.

9. Does it work for students and remote workers?
Yes. The checklist fits study tasks, work tasks and home tasks the same way.
