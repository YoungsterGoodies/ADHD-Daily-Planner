# Create a Notion Dashboard

A simple guide to building your own Notion dashboard for planning your day and week,
using the free files in this repository.

A dashboard is one page that shows only what matters today: your top tasks, your
habits, and what is coming up. No switching between apps, no long lists to scroll
through. If it is not on the dashboard, it is not today's problem.

## Step 1: Start with one page

Open Notion and make one page called "Today". This is your dashboard.

- Put today's date at the top.
- Keep only three sections on it: Tasks, Habits, and Events.
- If a section does not help you today, leave it out — a dashboard should be
  short enough to read in one minute.

## Step 2: Add a task list

Add a simple list for today's tasks.

1. Write your top 3 priorities for the day. Three is enough.
2. Write the first step of each task, not the whole task. "Open the document"
   starts; "finish the report" does not.
3. Tick a task Done as soon as you finish it.
4. At the end of the day, move unfinished tasks to tomorrow — do not leave them
   on today's page.

Use `daily-checklist.md` in this repository as your paper version of the same list.

## Step 3: Add a habit tracker

Add a small table with one row per habit and one column per day.

- Pick three small habits. Keep each one small enough to do every day.
- Do each habit at the same time each day, if you can.
- Tick the box each day you do it.
- A missed day is fine — start fresh the next morning.

Use `habit-tracker.md` in this repository as your paper version.

## Step 4: Add a weekly view

Add a short weekly section underneath, or on a second page.

1. Write one line of focus for the week.
2. Pick your top 3 priorities for the week.
3. Give each day one small step.
4. On Sunday, take 10 minutes to review the week and write next week's top 3.

Use `weekly-checklist.md` in this repository as your paper version.

## Step 5: Add a daily flow

A dashboard only works if you open it. Give it a simple routine:

1. **Morning (5 minutes):** open the dashboard, write today's top 3.
2. **During the day:** work in 25-minute blocks with 5-minute breaks, and tick
   tasks and habits Done as you finish them.
3. **Evening (5 minutes):** reset — tick what got done, move the rest to
   tomorrow, and pick tomorrow's top 3.
4. **Sunday (10 minutes):** review the week and set next week's focus.

That is the whole system: one page, three tasks, three habits, and a five-minute
reset at night.

## FAQ

1. What is a Notion dashboard?
   One page that shows only what matters today — your top tasks, your habits, and
   what is coming up — so you do not have to switch between apps.
2. Do I need a paid Notion plan to build one?
   No. A free Notion account is enough. A desktop browser is best for the first
   setup.
3. How many tasks should go on the dashboard?
   Three a day. Three tasks fit on one page and can actually be finished; a list
   of twenty only adds noise.
4. How do I start a task I keep avoiding?
   Write the first step, not the whole task — "open the document" instead of
   "finish the report". A clear first step has no decision in it.
5. What if I miss a task today?
   Move it to tomorrow in the evening reset. A missed task is not a failed day —
   the system bends, it does not break.
6. How do I track habits in the dashboard?
   One row per habit, one column per day. Tick the box each day you do it, and
   start fresh the next morning if you miss a day.
7. How long does the daily routine take?
   About five minutes in the morning and five minutes in the evening, plus a
   ten-minute weekly review on Sunday.
8. Can I use the free files in this repo instead of Notion?
   Yes. `daily-checklist.md`, `weekly-checklist.md` and `habit-tracker.md` are
   the paper versions of the same system.
9. Is the All In One Life Planner a printable?
   No. It is a live Notion template. You get a one-page PDF with the template
